اعمال پکیج اصلاح نام تصاویر Art / Sculpture
=================================================
مشکل: ۲۴ فایل در پوشه src/assets/images/products/ شما نام قدیمی دارند
ولی db.json نام‌های استاندارد را صدا می‌زند؛ برای همین ولیدیتور ۲۴ مسیر شکسته گزارش می‌کند.
محتوای فایل‌ها سالم است — فقط باید نام‌ها عوض شوند.

راه حل اول (پیشنهادی — تغییر نام خودکار)
-------------------------------------------------
۱) فایل rename-sculpture-images.ps1 را داخل روت پروژه (کنار package.json) کپی کنید.
۲) در ترمینال VS Code اجرا کنید:
      powershell -ExecutionPolicy Bypass -File .\rename-sculpture-images.ps1
   باید ۲۴ خط OK ببینید (Renamed: 24 / 24).

راه حل دوم (جایگزین — کپی دستی)
-------------------------------------------------
پوشه images این پکیج، همان ۲۴ عکس است با نام صحیح.
۱) محتوای پوشه images را داخل src/assets/images/products/ کپی کنید (Replace = Yes).
۲) سپس ۲۴ فایل با نام قدیمی را از همان پوشه حذف کنید:
   - art-sculpture-art-sculpture-bowl-il-passagio-liten-or-the-passage-small-designed-by-inger-sannes-1321-{1,2,3}.jpg
   - art-sculpture-art-sculpture-by-einar-hoste-1361-{1,2,3}.jpg
   - art-sculpture-art-sculpture-by-hugo-liisberg-3101-{1,2,3}.jpg
   - art-sculpture-art-sculpture-by-jorgen-larsen-3606-{1,2,3}.jpg
   - art-sculpture-art-sculpture-by-nils-g-stenqvist-1826-{1,2,3}.jpg
   - art-sculpture-art-sculpture-by-torsten-johansson-2401-{1,2,3}.jpg
   - art-sculpture-art-sculpture-designed-by-torsten-johansson-2259-{1,2,3}.jpg
   - art-sculpture-blasegel-designed-by-stig-ake-lund-868-{1,2,3}.jpg

بعد از هر دو راه — تست و کامیت
-------------------------------------------------
۱) تست خودکار:
      node tools/validate-images.mjs
   باید بگوید: all image paths OK

۲) کامیت و پوش:
      git add -A
      git commit -m "Add art sculpture subcategory: 15 products (ids 255-269)"
      git push

نکته: db.json این پکیج همان نسخه تاییدشده قبلی است (۱۵ محصول، id 255 تا 269،
مجموع ۲۶۹ محصول). اگر قبلا آن را کپی کرده‌اید، نیازی به کپی دوباره نیست.
